================================================================================
           便携式低压信号发生与测量终端 — 项目解决方案框架
           基于 STM32F103RCT6 | 大作业2 组队任务
================================================================================

一、项目概述
================================================================================
本项目要求基于 STM32F103RCT6 微控制器，设计并实现一台便携式低压测试终端。
设备具备三大核心功能：
  (1) 信号输出：DAC 模拟信号（直流 + 周期波形）与 PWM 数字脉冲
  (2) 信号测量：ADC 采集模拟/数字信号并在 OLED 显示，输入捕获测量脉冲频率
  (3) 参数存储与可靠性：Flash 保存工作参数，独立看门狗保障系统恢复

项目目标：完成基础任务全部验收项，并争取完成进阶任务。


二、硬件平台与引脚规划
================================================================================
【主控芯片】STM32F103RCT6（Cortex-M3, 72MHz, 256KB Flash, 48KB SRAM）

【外设模块】
  - OLED 显示屏：SSD1306 / 0.96寸，I2C 或 SPI 接口
  - 按键：3~4 个独立按键（模式切换 / 增减 / 保存返回）
  - USART：TTL 串口转 USB，用于调试输出
  - DAC：使用片上 DAC（PA4 通道1 / PA5 通道2）
  - PWM 输出：TIM 定时器通道（如 TIM3 CH1 -> PA6）
  - ADC 采集：ADC1 + DMA（如 PA1 通道1）
  - 输入捕获：TIM 定时器通道（如 TIM4 CH1 -> PB6）
  - Flash：使用芯片内部 Flash 用户区存储参数

【引脚分配规划（初版，可调整）】
  -------------------------------------------------------
  功能              | 引脚    | 外设
  -------------------------------------------------------
  OLED SCL         | PB8     | I2C1_SCL（或软件模拟）
  OLED SDA         | PB9     | I2C1_SDA（或软件模拟）
  DAC 输出          | PA4     | DAC_OUT1
  PWM 输出          | PA6     | TIM3_CH1
  ADC 采集          | PA1     | ADC1_IN1
  输入捕获          | PB6     | TIM4_CH1
  USART TX         | PA9     | USART1_TX
  USART RX         | PA10    | USART1_RX
  按键 KEY1 (模式)  | PA11    | GPIO 上拉输入
  按键 KEY2 (加/启) | PA12    | GPIO 上拉输入
  按键 KEY3 (减/停) | PA15    | GPIO 上拉输入
  按键 KEY3 (保存)  | PB1     | GPIO 上拉输入
  -------------------------------------------------------

【安全注意事项】
  - 调试时若将输出引脚与输入引脚短接，禁止将输出配为推挽、输入配为下拉，
    否则 3.3V 与 0V 直连有烧片风险。
  - 建议输出引脚配置为推挽时，输入引脚配置为浮空或模拟输入。
  - 或在输出与输入之间串联 1K 限流电阻进行保护。

================================================================================

3.1 软件整体架构

  │              应用层 (Application Layer)        │
  │   状态机 / 页面管理 / 参数管理 / 业务逻辑       │

  │              驱动层 (Driver Layer)             │

  ├──────────────────────────────────────────────┤
  │           HAL/标准库 (STM32 StdPeriph)         │
  ├──────────────────────────────────────────────┤

  │  STM32F103RCT6 + OLED + 按键 + 外部信号        │
  └──────────────────────────────────────────────┘

3.2 系统状态机
--------------------------------------------------------------------------------
  系统运行三个主要页面（状态），通过 KEY1 循环切换：

  ┌──────────────┐  KEY1  ┌──────────────┐  KEY1  ┌──────────────┐
  │  信号输出页   │ -----> │  信号测量页   │ -----> │  参数设置页   │
  │  (OUTPUT)    │ <----- │  (MEASURE)   │ <----- │  (SETTING)   │
  └──────────────┘        └──────────────┘        └──────────────┘

  信号输出页：
    - 显示当前输出类型（DAC直流 / DAC波形 / PWM）及参数值
    - KEY2 短按：启动输出
    - KEY3 短按：停止输出

  信号测量页：
    - 显示 ADC 采集波形 / 输入捕获频率测量结果
    - 自动切换模拟/数字测量模式

  参数设置页：
    - KEY2 短按：参数值递增 / 切换档位
    - KEY3 短按：参数值递减 / 切换档位
    - KEY3 长按 2s：保存参数到 Flash 并返回主页面

3.3 全局数据结构（建议）
--------------------------------------------------------------------------------
  typedef struct {
      uint8_t  page;            // 当前页面: 0=输出, 1=测量, 2=设置
      uint8_t  outputMode;      // 输出模式: 0=DAC直流, 1=DAC波形, 2=PWM
      uint8_t  dacDcLevel;      // DAC直流档位: 0=1.0V, 1=2.0V
      uint8_t  pwmFreqIndex;    // PWM频率档位: 0=100Hz, 1=1kHz, 2=5kHz
      uint8_t  pwmDutyIndex;    // PWM占空比档位: 0=25%, 1=50%, 2=75%
      uint8_t  outputEnable;    // 输出使能标志: 0=停止, 1=运行
      uint8_t  measureMode;     // 测量模式: 0=ADC模拟, 1=输入捕获频率
      uint8_t  paramIndex;      // 参数设置页当前选中项
      uint32_t adcValue;        // ADC最新采集值
      uint32_t freqValue;       // 频率测量值
  } SystemState_t;


四、各模块技术方案
================================================================================

4.1 系统交互模块
--------------------------------------------------------------------------------
  【OLED 显示】
  - 使用 SSD1306 驱动，I2C 通信
  - 分页显示：每页固定区域显示标题、参数值、波形
  - 波形显示区域：128x32 像素，ADC 采样点映射到屏幕坐标
  - 字符显示：使用 8x16 字库

  【按键处理】
  - 3 个独立按键，定时器 10ms 周期扫描去抖
  - 短按：按下后释放且持续 > 20ms
  - 长按：按下持续 > 2s，用于参数保存
  - 按键事件通过全局标志或回调通知应用层

  【页面切换】
  - 状态机管理三个页面，KEY1 触发循环切换
  - 每个页面有独立的显示刷新函数和按键处理逻辑

  【USART 调试输出】
  - USART1, 115200 baud, 8N1
  - 定时 1s 输出当前模式、输出设定值、测量结果
  - 使用 printf 重定向或自定义格式化函数

4.2 DAC 模拟信号发生模块
--------------------------------------------------------------------------------
  【DAC 直流输出】
  - 使用片上 DAC 通道1 (PA4)，12位分辨率
  - 1.0V 对应数字量：1.0/3.3*4095 ≈ 1241
  - 2.0V 对应数字量：2.0/3.3*4095 ≈ 2482
  - 直接写 DAC->DHR12R1 寄存器设置输出电压
  - 验收标准：万用表测得 1.0V/2.0V，误差 ≤ ±0.30V

  【DAC 周期波形输出】
  - 使用 wave.c 提供的 100 点三角波数据
  - DAC + DMA + 定时器触发（TIM6/TIM7）
  - 触发频率：100Hz × 100点 = 10kHz 触发率
  - 定时器配置：72MHz / (720-1) / (10-1) = 10kHz
  - DMA 循环模式，自动重载波形数据
  - 验收标准：示波器可观察到连续 100Hz 三角波

4.3 PWM 数字脉冲发生模块
--------------------------------------------------------------------------------
  - 使用 TIM3 CH1 (PA6) 输出 PWM
  - 频率档位：100Hz / 1kHz / 5kHz
  - 占空比档位：25% / 50% / 75%
  - 频率切换：修改 TIM3 的 PSC 和 ARR
    · 100Hz:  PSC=7199, ARR=99   (72MHz/7200/100 = 100Hz)
    · 1kHz:   PSC=719,  ARR=99   (72MHz/720/100 = 1kHz)
    · 5kHz:   PSC=143,  ARR=99   (72MHz/144/100 = 5kHz)
  - 占空比切换：修改 CCR1
    · 25%:  CCR1 = 25
    · 50%:  CCR1 = 50
    · 75%:  CCR1 = 75
  - 验收标准：三档频率和三档占空比均可切换，频率误差 ≤ 2%

4.4 ADC + DMA 信号采集与显示模块
--------------------------------------------------------------------------------
  【ADC 配置】
  - ADC1 通道1 (PA1)，12位分辨率
  - DMA 连续传输模式，采样率 ≥ 1kHz
  - 采集范围：0~3.0V（对应 0~3723 数字量，3.0/3.3*4095）
  - DMA 缓冲区：128 点，用于波形显示

  【波形显示】
  - 将 ADC 采样值映射到 OLED 坐标
  - X 轴：采样点序号 (0~127)
  - Y 轴：电压值反向映射 (0V=底, 3.0V=顶)
  - 刷新率：≥ 10Hz

  【数字信号采集】
  - 同样使用 ADC 采集，将数字电平波形显示在 OLED
  - 可显示方波高低电平切换

  【进阶：统计量计算】
  - 最大值、最小值、平均电压、峰峰值
  - 多周期平均，提高稳定性

  - 验收标准：测试 0.5V/1.5V/2.5V，显示误差 ≤ ±0.30V

4.5 输入捕获频率测量模块
--------------------------------------------------------------------------------
  【输入捕获配置】
  - TIM4 CH1 (PB6)，配置为输入捕获模式
  - 上升沿触发捕获，记录两次上升沿之间的计数差
  - 频率计算：f = TIM_CLK / (PSC+1) / capture_diff

  【测量范围】100Hz ~ 10kHz
  - 100Hz:  周期 10ms，计数差 = 72MHz/7200 * 10ms = 10000
  - 10kHz:  周期 0.1ms，计数差 = 72MHz/1 * 0.1ms = 7200
  - PSC 建议设为 71（72分频），使计数频率为 1MHz

  【无信号超时处理】
  - 启动一个 1s 超时定时器，每次捕获到信号时重置
  - 超时后清除频率显示，OLED 显示"无信号"
  - 验收标准：测试 100Hz/1kHz/5kHz，测量误差 ≤ 2%

  【进阶：占空比测量】
  - 先捕获上升沿，再切换为下降沿捕获
  - 高电平时间 / 周期 = 占空比

4.6 Flash 参数存储模块
--------------------------------------------------------------------------------
  【存储方案】
  - 使用 STM32 内部 Flash 最后几页（如 Page 127，地址 0x0807F800）
  - 存储内容：outputMode, dacDcLevel, pwmFreqIndex, pwmDutyIndex
  - 使用键值对或结构体直接写入

  【写入流程】
  1. 解锁 Flash (FLASH_Unlock)
  2. 擦除目标页 (FLASH_ErasePage)
  3. 按字写入数据 (FLASH_ProgramWord)
  4. 锁定 Flash (FLASH_Lock)
  5. 校验写入数据

  【上电恢复】
  - 系统初始化时读取 Flash 存储区
  - 校验魔数（如 0xA5A5），有效则恢复参数，无效则使用默认值

  - 验收标准：断电后恢复参数

4.7 独立看门狗 (IWDG) 模块
--------------------------------------------------------------------------------
  【IWDG 配置】
  - LSI 时钟约 40kHz
  - 预分频 IWDG_Prescaler_64：40kHz/64 = 625Hz
  - 重装载值 1875：1875/625 = 3s
  - 喂狗周期：在主循环中每 < 3s 喂狗一次

  【故障测试入口】
  - 提供一个按键组合（如同时按 KEY2+KEY3）或菜单选项触发故障
  - 触发后停止喂狗，持续 3s 后 IWDG 复位
  - 目标复位时间：约 2s

  【复位后处理】
  - 系统启动时关闭所有输出（DAC=0, PWM 停止, 输出使能=0）
  - 恢复 Flash 中的参数后正常进入系统
  - 可通过 RCC CSR 标志判断是否为 IWDG 复位

  - 验收标准：故障测试后自动复位并关闭输出


五、进阶任务规划
================================================================================
1. ADC 统计扩展
   - 最大值/最小值/平均电压/峰峰值计算与显示
   - 输入捕获占空比测量（上升沿+下降沿双捕获）

2. 测量稳定性优化
   - 多周期平均（取 N 次测量均值）
   - 测量超时/无效数据判断与过滤
   - 对比处理前后波形/数值的稳定性

3. DAC 波形扩展
   - 增加正弦波（预计算 100 点正弦表）
   - 幅值可调（缩放 DAC 输出数据）
   - 频率可调（修改定时器触发频率）

九、协作约定
================================================================================
1. 代码规范
   - 统一使用 STM32 标准库（StdPeriph），不混用 HAL
   - 文件命名：小写+下划线，如 dac.c, input_capture.c
   - 函数命名：模块名_动词_名词，如 DAC_SetDC, ADC_GetVoltage
   - 全局变量加 g_ 前缀，如 g_systemState
   - 每个模块提供 .h 头文件，声明对外接口

2. 版本管理
   - 使用 Git 管理代码，建立仓库
   - 分支策略：main（稳定）+ develop（开发）+ feature/xxx（功能分支）
   - 每完成一个模块提交一次，提交信息写明改动内容

3. 接口对接
   - 各模块开发前先约定好接口函数签名
   - 通过 SystemState_t 全局结构体传递状态
   - OLED 画点/画线函数由成员A统一提供，其他人调用

4. 硬件调试
   - 引脚分配由成员D统一管理，修改前通知所有人
   - 调试时注意安全提醒：输出和输入引脚短接时注意配置
   - 示波器、函数信号发生器等共用设备预约使用


十、风险与对策
================================================================================
  风险1：引脚冲突或外设资源冲突
  对策：开发前统一规划引脚分配表，由成员D维护

  风险2：DAC 波形输出频率不准
  对策：使用定时器触发 DMA 模式，精确控制触发频率；用示波器校准

  风险3：输入捕获高频时测量不稳定
  对策：合理设置定时器分频，增加多周期平均滤波

  风险4：Flash 写入失败或数据损坏
  对策：加入魔数校验和默认值回退机制

  风险5：系统集成时编译错误多
  对策：各模块先独立编译测试，接口提前约定，分步集成

  风险6：时间不足无法完成进阶任务
  对策：优先确保基础任务全部通过验收，进阶任务按优先级逐步推进
